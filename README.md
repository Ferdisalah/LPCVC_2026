LPCVC: Low-Power Computer Vision Optimization (Rank 11)
This repository showcases the optimization strategies and architectural innovations used to achieve Rank 11 in the Low-Power Computer Vision Challenge (LPCVC).
🔬 Technical Innovation: SurgicalNovelEdgeAI
This project features a custom-engineered model based on the R(2+1)D backbone, specifically designed for high-precision tasks on resource-constrained hardware.
🛠 Key Features:
Layer 4 Surgery: Modified spatial strides from 2 to 1 to maintain a 14*14 resolution. This allows for better spatial tracking of small objects compared to the standard 7*7 output.
Dual-Strip Attention: Implemented a unique spatial attention mechanism using Vertical and Horizontal pooling to pinpoint regions of interest with minimal FLOPs.

Focus on balancing accuracy with high inference speed on mobile DSPs.
